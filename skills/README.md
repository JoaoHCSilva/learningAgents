# Skills do Learning Agent

## 1. Integração automática com git hook
- Instala um hook post-commit para gerar explicações automáticas após cada commit.
- Use: `npx learning-agent --hook`

## 2. Explicação didática de diffs
- Gera explicações para arquivos alterados, podendo ser integrado com IA no futuro.

## 3. Listagem de arquivos alterados
- Lista rapidamente arquivos modificados desde o último commit.

---

Essas skills podem ser expandidas para integração com outras ferramentas, análise semântica, ou geração de quizzes para aprendizado.
